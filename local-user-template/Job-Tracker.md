# Job Tracker

| ID | Company | Role | Status | Last Action | Last Updated | Applied Date | Rubric Score | Interview Stage |
|---|---|---|---|---|---|---|---|---|

## Status Key

- **Applied** — Application sent; awaiting a response
- **Interviewing** — Active interview process
- **Active** — Packet or action in progress; not yet applied
- **Offer Pending** — Verbal or written offer expected
- **Offer Received** — Offer received
- **Closed - rejected** — Employer explicitly rejected the application
- **Closed - posting closed** — Official posting confirmed unavailable; no rejection message received
- **Closed - declined** — Applicant chose not to proceed

## Notes

- Keep one row per job ID.
- Preserve the original Applied Date when updating status.
- Closed packet folders belong under `_Archive/`.
